# 🏋️ TPulse Fitness

Landing page desenvolvida para apresentar uma proposta de gerenciamento e acompanhamento de treinos, com foco em organização, praticidade e evolução pessoal.

O projeto apresenta funcionalidades planejadas para uma plataforma fitness, além de disponibilizar acesso a uma planilha de treinos.

### 🔗 Demonstração

**[Acessar TPulse Fitness](https://talyttacarvalho.github.io/tpulse-fitness/)**

### ✨ Funcionalidades apresentadas

- Organização e criação de treinos
- Acompanhamento da evolução física
- Registro de dados de bioimpedância
- Catálogo adaptável de exercícios
- Acesso a uma planilha de treinos

> **Nota:** este projeto é uma landing page demonstrativa. As funcionalidades de gerenciamento são apresentadas como conceito e não estão implementadas como um sistema completo.

### 🛠️ Tecnologias

- **HTML5** — estrutura da página
- **CSS3** — estilização e layout
- **Font Awesome** — ícones da interface
- **GitHub Pages** — publicação do projeto
